The anatomy of a good build prompt

Role · Goal (user + outcome) · Context (spec, stack, files) · Constraints (scope, style, what not to touch) · Acceptance criteria (how we'll know it's done) · Output format · "Ask me if anything is unclear before you start."

Tool-specific tips

ToolTips
Claude CodePlan mode first (Shift+Tab), reference files with @, keep CLAUDE.md short, /clear between unrelated tasks, use /rewind or git to undo.
Lovable / BoltUse the chat/plan mode for questions so you don't burn credits on edits; connect Supabase for DB/auth; pin a working version before risky prompts.
v0Great for UI and Next.js components; paste a screenshot or describe the layout; export to your repo when done.
CursorUse rules files for conventions; agent mode for multi-file changes; review each diff before accepting.
ReplitAgent builds full-stack with hosting included; good when you need a backend and a live URL fast.
