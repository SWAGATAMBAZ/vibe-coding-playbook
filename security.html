The 12 holes vibe-coded apps ship with

#HoleFix
1API keys in frontend code or committed to gitServer-only env vars; .env in .gitignore; rotate anything leaked; secret scanning on the repo.
2Database open to the public (no RLS / exposed anon key with no policies)Enable RLS on every table with per-user policies; test as a second user.
3Authentication but no authorization (any logged-in user can read /api/orders/123)Check ownership on the server for every request (IDOR).
4No input validationzod/pydantic schemas on every endpoint; size limits.
5SQL injection / XSSParameterised queries/ORM; never dangerouslySetInnerHTML with user data; sanitise markdown from LLMs.
6No rate limiting on AI and auth endpointsPer-user and per-IP limits; daily AI budgets; CAPTCHA on signup.
7Prompt injectionSeparate system instructions from user/tool content; never let model output trigger privileged actions without checks; allow-list tools; human approval for side effects.
8Sensitive data sent to the LLM or loggedMinimise and redact PII; aggregate stats instead of raw notes; scrub logs and error trackers.
9Hallucinated or malicious packages ("slopsquatting")Verify every new dependency exists and is popular; lockfiles; dependency audit.
10Wide-open CORS and missing security headersAllow only your origins; CSP, HSTS via the framework/host.
11Unverified webhooksVerify signatures (Stripe, GitHub); idempotent handlers.
12Verbose errors leaking internalsGeneric messages to users; details only in server logs.

AI-specific risks (OWASP LLM-style)

Prompt injection

Direct ("ignore previous instructions") and indirect (instructions hidden in a web page, PDF or email the agent reads).

Sensitive information disclosure

The model reveals system prompts, other users' data, or secrets in context.

Excessive agency

Agents with too many tools or permissions taking real actions unchecked.

Insecure output handling

Rendering or executing model output (HTML, SQL, shell) without validation.

Unbounded consumption

Cost and denial-of-wallet from long prompts, loops, or abuse.

Misinformation

Confident wrong answers. Ground with RAG + citations, show uncertainty, add human review for high stakes.
