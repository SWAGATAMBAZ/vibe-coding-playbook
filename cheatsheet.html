One-page cheat sheet

Read this the night before. Print it with Ctrl+P; the sidebar hides automatically.

The loop: C-S-B-V-M (45 min)

Clarify 0–7: goal → segments → pick one → pains → pick one → your solution.
Spec 7–14: persona PRD from your decisions → review aloud → self-critique → lock scope.
Build 14–31: happy path with mocks → one feature per prompt.
Verify 31–39: click through, edge cases, precise fix prompts.
Metrics 39–45: north-star, guardrail, risks, AI guardrails, next.

Opening script

"Let me restate the problem… I'll spend ~7 minutes on scope, build the core flow with the AI, test it, and finish with metrics and risks. First: what's the business goal, and who do you see as the main user?"

What's scored

Human delta · strategic leverage · product direction · audit & redirect · verification · narration. Judgement, not prompts.

Build prompt anatomy

Role · goal (user + outcome) · context (spec, stack) · constraints (scope, don't touch) · acceptance criteria · output format · "ask if unclear".

10 checks before "done"

Empty state · long input · invalid input · double submit · failed/slow AI call · mobile width · second user can't see data · no key in client · console clean · acceptance criteria all pass.

When it breaks

Narrate → read the error → precise fix prompt (steps, expected, actual, error) → two strikes = revert & shrink scope → mock it honestly and move on.

Default stack line

"Next.js + Tailwind + shadcn, Supabase for Postgres, auth and RLS, LLM calls server-side with validated JSON, timeout and fallback, deployed on Vercel."

System design names

CDN · load balancer · API gateway (auth, rate limit, routing) · stateless services · Redis cache · Postgres + replicas · queue + workers · object storage · LLM gateway (routing, fallback, caching, budgets) · observability + evals.

Database line

"Postgres first: relational + jsonb + pgvector. Redis when we need caching/rate limits; a dedicated vector DB past millions of vectors or heavy filtering; OLAP for event analytics."

Agent line

"Simplest thing first: one call → workflow → agent only if steps vary. Least privilege, human approval for irreversible actions, step and cost budgets, traces and evals. n8n for ops automation, LangGraph for stateful product agents, Claude Agent SDK for tool-rich agents."

MCP line

"MCP is a standard protocol so agents can use tools and data: servers expose tools, resources and prompts; the host connects to them. N+M integrations instead of N×M. Watch for prompt injection and give least privilege."

Wrap-up metrics

North-star tied to user value · 2–3 inputs · guardrail (quality, cost, latency, complaints) · one experiment (hypothesis, variant, success criterion).

AI guardrails

Show sources/confidence · edit/undo · human review for high stakes · input/output filters · minimal PII to the model · evals before launch · monitoring after.
