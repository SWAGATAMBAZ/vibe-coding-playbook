Claude Code · 05

Starter kit: the files you drop into every repo

A CLAUDE.md template, 7 custom commands, 3 hooks, a reviewer subagent, shared connectors and a one-shot installer. Together they turn the playbook into muscle memory: /kickoff → /slice → /verify → /ship → /demo.

Get the files

They're all in this site's repo under starter-kit/. Clone the repo and copy the folder's contents (including the hidden .claude/) into your project root, or copy each file from below.

One-file setup on any laptop

SETUP.md is written for Claude Code to carry out. Claude checks the laptop, copies this starter kit, and installs the plugins, skills and connectors for the profile you choose (core, interview, ai or full). It merges with your existing files instead of overwriting them, then reports what it installed. It also saves itself as a personal /setup-vibe-stack command, so on that computer every later project is one command.

Afterwards: reload the window, run /mcp to log in to the connectors, and type / to see your commands. Claude asks before installing system software (Node, Git, Python, uv) and never uses sudo on its own.

The command flow

/kickoffclarify → spec.md → tasks.md
→
/slicenext task, test-first, commit
↺
/verifyprove acceptance criteria
→
/shipreview + security + PR
→
/demoscript, metrics, risks

Plus /metrics to instrument success and /handoff before you /clear. Each command orchestrates skills you already installed (grill-me style questioning, TDD, Playwright, code review) rather than duplicating them. If you use Spec Kit instead, swap /kickoff for the /speckit.* commands and keep the rest.

Settings & hooks

Hooks are the guarantees. CLAUDE.md says "run tests before you finish"; the Stop hook makes it true. Three hooks cover most of the risk in vibe-coded work:

EventHookWhy
PreToolUse (Bash)block-dangerous.shStops destructive git, deletes, destructive SQL, printing secrets, curl | bash.
PostToolUse (Edit|Write)format.shConsistent formatting with zero tokens spent.
Stoptests-must-pass.shClaude can't declare victory while tests fail. Checks stop_hook_active to avoid loops.
